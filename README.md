# Project Portfolio

A growing collection of independent analytics and software projects. Each project has its own folder under `projects/`, with its documentation, source files, data, and outputs kept together.

## Projects

### Project 1: Token Analytics

An insight-led case study exploring whether AI-assisted work creates enough modeled value to justify its token cost. The project uses synthetic data and includes a dashboard, SQL analysis, and reproducible PowerShell scripts.

- [Open the project files](projects/01-token-analytics/)
- [Read the project README](projects/01-token-analytics/README.md)
- [Open the dashboard source](projects/01-token-analytics/reports/dashboard.html)
- [Read the SQL analysis](projects/01-token-analytics/sql/analysis.sql)

### Project 2: SaaS Customer Funnel & Lifecycle Analytics

A local DuckDB and Streamlit analytics project covering signup-to-paid conversion, funnel velocity, channel economics, and estimated CAC/payback using explicitly synthetic source data.

- [Open the project files](projects/02-saas-funnel-analytics/)
- [Read the project README](projects/02-saas-funnel-analytics/README.md)
- [Open the dashboard source](projects/02-saas-funnel-analytics/app.py)
- [Read the channel economics SQL](projects/02-saas-funnel-analytics/sql/04_channel_economics.sql)

## Organization

```text

    sql/

    README.md
  02-saas-funnel-analytics/
    data/

    screenshots/

```

Add future projects as separate, numbered folders under `projects/` (for example, `02-project-name/`). Keep each project's documentation and supporting files in its own folder.
